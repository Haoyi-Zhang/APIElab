# External materials and redistribution boundary

All experimental inputs and implementation code in this standalone repository were authored/generated for this project. No third-party solver, parser, benchmark implementation, scholarly PDF, or library source is incorporated. Python's standard library is used as a runtime dependency and is not redistributed. Published algorithms are discussed with attribution, not copied as code.

The external-resource ledger identifies the exact inspected research and official sources. A publicly readable PDF is not assumed redistributable. In particular, the author copy of Outcome Logic explicitly disallows redistribution; it is not included. The CiD copy permits personal/classroom copying under conditions, but is not redistributed in this repository. Other inspected scholarly materials are likewise linked rather than bundled. Reproducing the finite experiments requires none of these PDFs.

The separate project paper directory retains the unmodified ACM class, bibliography style, and license from the user's supplied template. They are not in this repository and are not covered by its MIT license. Their distribution-source condition and the unavailable matching source are described with the paper. No claim that this repository grants publisher-asset rights is made.
